## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# writes out/entry.png (1024x1024 PNG, under 1 MiB)
```

`main.ts` (Node 22, standard library only) copies `entry.png` — rendered from
`design.html`, the hand-written HTML/CSS/SVG front page — into the output
directory. `index.html` is the referral landing page for this entry, and
`ad.png` is a screenshot of it.
